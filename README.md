# VST3 Latency

Приложение для macOS 26. При запуске оно сканирует стандартные папки VST3, включая
`/Library/Audio/Plug-Ins/VST3` и `~/Library/Audio/Plug-Ins/VST3`.

Для каждого найденного класса программа создаёт отдельный экземпляр для каждой
частоты (44,1 и 88,2 кГц) и считывает заявленную задержку после подготовки
к обработке с блоком в 512 сэмплов. Число в скобках показывает сэмплы, рядом указаны
миллисекунды. Щелчок по заголовку сортирует таблицу, повторный меняет направление.
Знак «—» означает, что получить значение не удалось.

Значения относятся к исходным настройкам каждого плагина. Режимы oversampling,
lookahead, пресеты и размер блока могут изменить задержку. Программа не измеряет
задержку по аудиосигналу и не учитывает буферы интерфейса или DAW. Пакеты
обрабатываются в отдельных процессах с лимитом 30 секунд на пакет.

## Сборка на Mac

Нужны Xcode с поддержкой macOS 26, CMake 3.22 или новее, Git и доступ к GitHub
для получения JUCE. Запустите команды в папке с этим файлом.

```sh
cmake -S . -B build -G Xcode
cmake --build build --config Release
open "build/VST3Latency_artefacts/Release/VST3 Latency.app"
```

По умолчанию сборка использует архитектуру текущего Mac. Для плагинов,
у которых есть только Intel-версия, на Mac с Apple Silicon соберите приложение
с `-DCMAKE_OSX_ARCHITECTURES=x86_64` в отдельной папке и запускайте через Rosetta.

Кнопки «Сохранить TXT» и «Сохранить Excel» выгружают отсортированную таблицу после сканирования. TXT разделён табуляцией, а XLSX содержит числовые ячейки для задержек.

Столбец «Категория» берётся из метаданных VST3. Результаты сохраняются в кэше. Состав установленных пакетов сверяется один раз при запуске приложения. Неизменённые успешно проверенные пакеты читаются из кэша, удалённые исчезают из таблицы.
